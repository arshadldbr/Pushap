🔄 Repo Sync

Apna GitHub token yahan browser mein hi rehta hai — kisi server ko nahi jata. Seedha aap ke apne repo ko update karta hai.

Fine-grained token, sirf apni target repo tak "Contents: Read and write" permission ke sath banayein.

Yeh poori folder (sub-folders sameet) select karta hai, structure bilkul waisa hi rahega.

Yeh sirf inn files ko unke naam se root mein push karega (koi folder-path nahi hoga).
